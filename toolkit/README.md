# Marketer's Toolkit

**تطوير: محمد صبري | Mohamed Sabry**

إضافة كروم واحدة فيها أدوات المسوّق اليومية. كلها مجانية، والبيانات بتتحفظ على جهازك.

## الأدوات
| الأداة | فين | بتعمل إيه |
|---|---|---|
| **الردود الجاهزة** | جوه واتساب ويب | اكتب `/` + الاختصار (مثلًا `/سعر`) والرد يتكتب باسم العميل. إنت اللي بتدوس إرسال |
| **CRM واتساب** | زرار CRM الأحمر جوه واتساب ويب + الداشبورد | تصنيف العملاء، والملاحظات، وتذكير بالمتابعة كإشعار، وتاج جنب اسم الشات، وتصدير Excel |
| **ContactHarvest** | الإضافة ← ContactHarvest | تصدير كل أرقام واتساب لإكسيل |
| **لينك واتساب + QR** | الداشبورد | لينك wa.me برسالة جاهزة وكود حملة، و QR بالأسود أو الأحمر (PNG/SVG) |
| **مراجع البوست** | الداشبورد | الطول، والـ Hook، والهاشتاجات، والـ CTA، والنص على التصميم (3–12 كلمة) لكل منصة |
| **أرشيف الإعلانات** | زرار على كل إعلان في Meta Ad Library + الداشبورد | حفظ إعلانات المنافسين بالصورة والنص وملاحظاتك |
| **فحص الصفحة** | الإضافة ← افحص الصفحة | Meta Pixel، وGA4، وGTM، وGoogle Ads، وTikTok، وSnap، وLinkedIn، وClarity، وHotjar + SEO + شكل المشاركة |
| **UTM Builder** | الداشبورد أو كليك يمين | نظام تسمية ثابت، وقوالب Meta/TikTok الديناميك، ومكتبة، وQR |
| **حاسبة الحملات** | الداشبورد | CPM، وCTR، وCPC، وCPL، وCAC، وROAS، وROI + الميزانية المطلوبة من الهدف وتقسيمها |
| **Notion** | الإضافة أو كليك يمين ← "احفظ على Notion" | حفظ أي صفحة أو نص أو صورة في قاعدة بيانات المحتوى |

## التثبيت
1. فك ضغط الملف في فولدر.
2. افتح `chrome://extensions` وفعّل **Developer mode**.
3. دوس **Load unpacked** واختار الفولدر.

## ملاحظات
- **Notion** محتاج مفتاح Integration مجاني، والخطوات مشروحة جوه تبويب Notion.
- أدوات واتساب ويب وMeta Ad Library بتشتغل جوه صفحات المواقع دي. فلو الموقع غيّر شكل الصفحة، الأداة ممكن تحتاج تعديل بسيط.
- حدود المنصات في مراجع البوست موجودة في `tools/post.js` (`PLATFORMS`)، وتقدر تعدّلها لو المنصة غيّرتها.
- الخطوط: Cairo وInter (رخصة SIL OFL)، ومكتبة QR: qrcode-generator (رخصة MIT).
